# Closed Dynamics – Cost Analysis Dashboard

## Business Problem

The company exceeded its monthly budget by $1.4M.

## Objective

Identify the departments and projects responsible for the cost variance.

## Tools Used

- Microsoft Excel
- Pivot Tables
- Power Pivot
- Slicers

## Key Findings

- Delayed hardware renewals increased costs.
- Help Desk expenses were higher than expected.
- The largest project was not the main source of the budget variance.
